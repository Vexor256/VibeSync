# VibeSync 🎵

VibeSync is a full-stack mood-based music recommendation application that analyzes a user's facial expressions and suggests songs that match their current mood.

## Features

* User Authentication (Register/Login)
* Facial Expression Detection using MediaPipe
* Mood Detection
* Personalized Song Recommendations
* Music Player Interface
* Song Management
* Secure Backend APIs
* MongoDB Database Integration
* Redis Caching

## Tech Stack

### Frontend

* React
* Vite
* React Router
* Axios
* SCSS

### Backend

* Node.js
* Express.js
* MongoDB
* Redis
* JWT Authentication
* ImageKit

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the backend directory and configure:

* MongoDB URI
* Redis URL
* JWT Secret
* ImageKit Credentials
